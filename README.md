# Industrial Doc Flow

**Автоматизация процесса создания документооборота промышленного предприятия.**

Десктопное приложение (Windows / Linux / macOS) для ведения внутреннего документооборота: создание документов из шаблонов, маршруты согласования, экспорт в PDF, журнал аудита.

Технологии: **Electron 32** + **React 18** + **TypeScript** + **better-sqlite3** + **TailwindCSS**.

![login](docs/images/01-login.png)

## Возможности

- Авторизация пользователей с ролями: **Сотрудник**, **Руководитель**, **Администратор**
- Создание документов из 5 преднастроенных шаблонов:
  - Служебная записка
  - Заявка на материалы
  - Приказ
  - Акт (приёмки / списания / выполненных работ / брака)
  - Заявка на ремонт оборудования
- Автоматическая генерация уникальных номеров (`MEMO-2026-0001`, `ORDER-2026-0007`, …)
- Последовательные маршруты согласования с произвольным числом шагов
- Полный жизненный цикл документа: `черновик → на согласовании → утверждён / отклонён → исполнен → в архиве`
- Поиск и фильтрация по статусу, автору, тексту
- Экспорт документа в PDF (с поддержкой кириллицы) и печать
- Журнал аудита всех действий пользователей
- Локальная база SQLite — не нужен сервер, всё работает offline

## Быстрый старт

```bash
git clone <repo-url>
cd industrial-doc-flow
npm install
npm run dev
```

Сборка production-версии:

```bash
npm run build           # компиляция main + preload + renderer
npm run dist            # сборка инсталлятора (.exe / AppImage / dmg)
```

## Тестовые учётные записи

| Логин         | Пароль        | Роль             | Должность                |
| ------------- | ------------- | ---------------- | ------------------------ |
| `admin`       | `admin123`    | Администратор    | Администратор системы    |
| `director`    | `director123` | Руководитель     | Генеральный директор     |
| `manager`     | `manager123`  | Руководитель     | Начальник цеха           |
| `employee`    | `employee123` | Сотрудник        | Инженер-технолог         |
| `storekeeper` | `store123`    | Сотрудник        | Кладовщик                |

> При первом запуске приложение создаёт SQLite-БД в каталоге пользовательских данных Electron (`~/.config/Industrial Doc Flow/doc-flow.sqlite` на Linux, `%APPDATA%/Industrial Doc Flow/` на Windows) и наполняет её тестовыми данными.

## Структура проекта

```
industrial-doc-flow/
├─ src/
│  ├─ main/                 # Electron main process
│  │  ├─ db/                # SQLite, миграции, сидинг
│  │  ├─ services/          # Бизнес-логика (auth, documents, pdf, …)
│  │  ├─ ipc.ts             # Регистрация IPC-обработчиков
│  │  └─ index.ts           # Точка входа
│  ├─ preload/              # Безопасный мост renderer ↔ main
│  ├─ renderer/             # React UI
│  │  └─ src/
│  │     ├─ pages/          # Login, Dashboard, DocumentsList, …
│  │     ├─ components/     # Layout, StatusBadge
│  │     ├─ store/          # Zustand store (auth)
│  │     └─ lib/            # Утилиты, словари
│  └─ shared/types.ts       # Общие TypeScript-типы
├─ docs/                    # Проектная документация (рус.)
│  ├─ 01-explanatory-note.md
│  ├─ 02-user-guide.md
│  └─ 03-installation.md
├─ electron.vite.config.ts
├─ electron-builder.yml
└─ package.json
```
